# User Guide

## Fake Rider Motorparts Web-Based Appointment Scheduling System

This guide explains how customers and administrators use the Fake Rider Motorparts Web-Based Appointment Scheduling System. Customers can book, view, cancel, or request to reschedule appointments without creating an account. Administrator-only functions require an authorized administrator account.

## 1. System Requirements

Before using the system, make sure that you have the following:

- A desktop computer, laptop, tablet, or smartphone.
- A stable internet connection through Wi-Fi, broadband, or mobile data.
- A current web browser, such as Google Chrome, Microsoft Edge, Mozilla Firefox, or Safari, with JavaScript enabled.
- The official Fake Rider Motorparts website address.

The system works on current versions of Windows, macOS, Linux, Android, and iOS that support a modern web browser. No software installation is required.

## 2. Accessing the System

1. Connect your device to the internet.
2. Open a supported web browser.
3. Enter the official Fake Rider Motorparts website address.
4. Wait for the home page to load.
5. Select **Book a Service** or the appointment-booking option to begin.

Customers do not need to create an account or sign in to use the booking and appointment-management pages.

## 3. Customer Functions

### 3.1 Booking a Service Appointment

1. Open the **Book a Service** page.
2. Enter your personal information:
   - Last name and first name
   - Middle name, if applicable
   - Mobile number
   - Email address
3. Select your motorcycle brand and model from the catalog, then enter its plate number.
4. Select one or more services. Use the search box or category filter if needed.
5. Choose whether you would like to add available products or parts, if that option is shown.
6. Select an available appointment date and time. The system displays availability based on the selected services and motorcycle model.
7. Enter additional notes when necessary.
8. Review the appointment details, including the services, estimated amount, date, and time.
9. Read and accept the Terms and Conditions.
10. Submit the appointment request.
11. Save the booking reference code shown after submission. You will need it to view or manage the appointment later.

New appointment requests are initially recorded as **Pending** until the shop reviews them.

### 3.2 Viewing an Appointment

1. Open the **My Appointment** page.
2. Enter the booking reference code.
3. Select **Search** or the corresponding lookup button.
4. Review the displayed customer, motorcycle, service, schedule, and appointment-status information.

If you cannot find the appointment, make sure that the reference code is correct and contains no extra spaces.

### 3.3 Recovering a Lost Reference Code

1. On the **My Appointment** page, select **Forgot your reference code?**
2. Enter the email address used when the appointment was booked.
3. Select **Send verification code**.
4. Enter the verification code sent to that email address.
5. Select **Email my reference code**.

Use the recovered reference code to view the appointment.

### 3.4 Cancelling an Appointment

1. Look up the appointment on the **My Appointment** page.
2. Select **Cancel Appointment** when the option is available.
3. Complete the email-verification step when prompted.
4. Confirm the cancellation.
5. Check that the appointment status changes to **Cancelled**.

Online cancellation is available only for appointments that are still eligible under the shop's cancellation policy. The system may prevent cancellation when the appointment status, notice period, or appointment history does not permit it.

### 3.5 Requesting a Reschedule

1. Look up the appointment on the **My Appointment** page.
2. Select **Reschedule Appointment** when the option is available.
3. Complete the email-verification step when prompted.
4. Choose a new available date and time.
5. Enter the reason for the request.
6. Read and accept the Terms and Conditions.
7. Review and submit the reschedule request.
8. Save the new reference code shown by the system.

The original appointment remains reserved while the shop reviews the reschedule request. The new schedule becomes active only after approval.

## 4. Administrator Functions

Only authorized administrators can access the administrative dashboard.

### 4.1 Signing In

1. Open the Fake Rider Motorparts website.
2. Open the administrator sign-in page.
3. Enter the authorized administrator email address and password.
4. Select **Log In**.
5. After successful authentication, the administrator dashboard opens.

### 4.2 Using the Dashboard

The dashboard provides a summary of appointments, customers, service activity, and other operational information. Use the navigation menu to open the required management page.

### 4.3 Managing Appointments

1. Open **Appointments Management**.
2. Use the list, search field, filters, or date controls to locate an appointment.
3. Open the appointment record to review its customer, motorcycle, service, schedule, product, and note details.
4. Use the available actions to review, confirm, update, reschedule, start, complete, cancel, or otherwise manage the appointment when appropriate.
5. Save or confirm the action, then verify that the updated status and details are correct.

### 4.4 Managing Services, Products, and Motorcycle Models

1. Open **Services**, **Parts & Accessories**, or **Motorcycle Catalog**.
2. Select the action you need, such as **Add**, **Edit**, **Archive**, or **Restore**.
3. Enter or update the required details. Depending on the record, these may include the name, description, category, price, duration, stock quantity, image, motorcycle brand, or motorcycle model.
4. Save the record.
5. Confirm that active services, products, and motorcycle models appear correctly on the relevant customer-facing page.

### 4.5 Managing Prices

1. Open **Prices Management**.
2. Select the service or product that needs a price update.
3. Enter the new price and save the change.
4. Confirm that the displayed price is correct.
5. Review the price history when it is available.

### 4.6 Managing Mechanics, Availability, and Schedule Blocks

1. Open **Mechanics** to add, edit, archive, or review mechanic records.
2. Open **Availability** to configure the dates and working hours of the mechanics or crew.
3. Open **Schedule Blocks** to block dates or time ranges that should not be available for booking.
4. When adding a schedule block, enter the date, time range, and reason as requested.
5. Save the changes and check the booking schedule to confirm that availability is correct.

### 4.7 Managing Customers and Blocked Customers

1. Open **Customer List** to search for customers by name or mobile number and review their appointment history.
2. Open **Blocked Customers** to manage customer numbers that should not be allowed to submit new bookings.
3. Confirm each action before saving changes to customer or blocking records.

### 4.8 Reviewing Notifications, Reports, Activity Logs, and Archives

1. Open **Notifications** to review system alerts and pending actions, including applicable appointment or reschedule notifications.
2. Open **Reports** to select a report and date range, then review or export the available report output.
3. Open **Activity Log** to review recorded administrator and system activity. Use an available export option when an external copy is needed.
4. Open **Archive** to review archived records and restore them when appropriate.
5. Use permanent deletion only when it is necessary and permitted by the shop's record-retention policy.

### 4.9 Managing System Settings

1. Open **Settings**.
2. Update the available shop, booking, or system settings as needed.
3. Save the changes.
4. Review the affected booking or administrator page to confirm that the setting was applied correctly.

## 5. Troubleshooting

### 5.1 The Website Does Not Open

- Check your internet connection.
- Refresh the browser page.
- Confirm that the website address is correct.
- Try another supported browser or restart the device.

### 5.2 An Appointment Cannot Be Submitted

- Complete all required fields.
- Select a motorcycle, at least one service, an available date, and an available time.
- Review the validation messages beside the affected fields.
- Accept the Terms and Conditions before submitting.
- Wait for the current request to finish before selecting the submit button again.

### 5.3 No Appointment Time Is Available

- Choose another date.
- Try a different combination of services or a different available time.
- Check again after the shop updates its mechanics' availability or schedule blocks.
- Contact Fake Rider Motorparts if no suitable schedule is available.

### 5.4 A Reference Code Does Not Work

- Enter the code exactly as shown, without extra spaces.
- Use the **Forgot your reference code?** option to recover the code through the booking email address.
- Contact the shop if the appointment still cannot be located.

### 5.5 An Administrator Cannot Sign In

- Check the internet connection.
- Confirm that the administrator email address and password are correct.
- Check for typing errors or unintended spaces.
- Contact the person responsible for system administration if access remains unavailable.

### 5.6 Information Does Not Update

- Wait briefly, then refresh the page.
- Reopen the appointment or record to check its current state.
- Avoid submitting the same action repeatedly while a request is still processing.
- Contact the system administrator if the information remains unchanged.

## 6. Support

For help with booking, viewing, cancelling, or rescheduling an appointment, contact Fake Rider Motorparts using the shop's official contact information. For administrator-access or system-management concerns, contact the authorized system administrator.

Add the shop's verified phone number, email address, website address, and business hours before distributing this guide. Do not insert unverified contact details.
